Student Attendance Management System

A simple and beginner-friendly Student Attendance Management System developed using HTML, CSS, and JavaScript. This project is suitable for first-year college students and demonstrates basic web development concepts.

📌 Project Overview

Managing student attendance manually can be time-consuming and can lead to calculation errors. This system provides a simple digital solution to add students, mark their attendance, calculate attendance percentages, search students, and delete student records.

🎯 Objectives

Add student details such as roll number and name.

Mark students as Present or Absent.

Automatically calculate attendance percentage.

Search for students using their name or roll number.

Delete student records.

Store attendance data in the browser using Local Storage.

🛠️ Technologies Used

HTML5 – Creates the structure of the application.

CSS3 – Provides styling and responsive design.

JavaScript – Handles attendance calculations and application functionality.

Local Storage – Stores student data in the browser.

✨ Features

1. Add Student

Users can enter:

Roll Number

Student Name

2. Mark Attendance

Each student can be marked as:

✅ Present

❌ Absent

3. Attendance Percentage

The system automatically calculates:
Attendance % = (Present Classes / Total Classes) × 100

4. Search Student

Students can be searched using:

Name

Roll Number

5. Delete Student

Student records can be removed from the system.

6. Data Persistence

Student information is saved using browser Local Storage, so the data remains available after refreshing the page.

📂 Project Structure

Student-Attendance-Management-System/ │ ├── attendance.html └── README.md

🚀 How to Run

Download or clone this project.

Open the attendance.html file.

Open it using a web browser such as Chrome or Edge.

Enter the student's roll number and name.

Click Add Student.

Use the Present and Absent buttons to maintain attendance.

💻 Example

If a student has:
Present = 8 Absent = 2 Total Classes = 10 
The system calculates:
Attendance = (8 / 10) × 100 = 80%
